# Migrations

Alembic migrations for the durable schema (DESIGN.md §7, §18.4).

`env.py` (async) is generated by `alembic init -t async .` when Phase 1 begins,
then wired to read `settings.database_url` and target `app.db.base.Base.metadata`.
Autogenerate the first revision once the §7 models exist:

```bash
alembic revision --autogenerate -m "initial schema"
alembic upgrade head
```

Migrations run as a dedicated release step, never opportunistically by every
replica (DESIGN.md §18.4).
